# FundamenTracker product context

## Surface mode

Operate. This is a private working tool for researching companies, monitoring valuation metrics, and reviewing triggered alerts. It should help the user complete a task quickly rather than persuade, entertain, or advertise.

## Primary user

A single long-term fundamental investor who uses the application on desktop and Android, often checking it briefly between other activities. The user values correctness, traceability, and compact explanations more than visual spectacle.

## Core jobs

1. See whether any valuation or quality alerts need attention.
2. Add or adjust an alert without leaving the current context.
3. Review the state, priority, and research material for a company.
4. Explore one metric and understand its source, period, formula, and history.
5. Run a scan and understand when the next automatic scan will occur.

## Voice

Calm, analytical, direct, and human. Use plain language and specific actions. Avoid hype, vague productivity claims, celebratory copy, and anthropomorphic AI language.

## Interaction priorities

- Mobile touch targets must be comfortable.
- Important actions use text labels, not unexplained icons.
- Secondary controls are progressively disclosed.
- Destructive actions remain explicit and confirmed.
- Loading, empty, stale, triggered, paused, and error states are unambiguous.
- A missing historical series must never be replaced with fabricated history.
